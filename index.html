Dev Vault has no API on purpose. Start at AGENTS.md, read catalog/index.json once, then open only the resource directories that survive filtering.

Contribute

Add a resource

One resource, one source of truth. No duplicates, no agent-specific copies, no unverified snippets.

  1. 1
    Search the catalog

    If an equivalent resource exists, improve it instead.

  2. 2
    Place it correctly

    resources/<type>/<kebab-case-name>/ with RESOURCE.md — or SKILL.md for skills.

  3. 3
    Add exactly one catalog entry

    Unique kebab-case id, valid path, and status: experimental unless you have evidence.

  4. 4
    Validate and test

    Both checks are standard-library Python. If they fail, the PR is not ready.

terminal 
# 1 — validate catalog, schema, and structure
$ python3 scripts/validate.py

# 2 — run the tooling test suite
$ python3 -m unittest discover -s tests

# 3 — open a PR against main
$ gh pr create --base main
