## 🧭 Why Dev Vault?

Engineers solve the same problems repeatedly — parsing JSON safely, cleaning up Git branches, writing Docker compose files, auditing repositories, drafting AI prompts. These solutions often get lost in chat history, old projects, or scattered notes.

**Dev Vault fixes that.** It is a curated, verified, and reusable collection of engineering resources that:

- **Eliminates redundant work** by making past solutions discoverable
- **Preserves engineering knowledge** across projects and time
- **Enforces quality** through verification and documentation
- **Reduces risk** by centralizing security-conscious patterns

> **Engineering principle:** *Before you build, search. Before you store, verify. Before you share, document.*

## ✨ Features

| Category | Capability |
|---|---|
| 🧩 **Snippets** | Reusable, single-purpose code utilities |
| ⚙️ **Scripts** | Automation for backup, cleanup, setup, and more |
| 🛠️ **Configs** | Safe configuration templates with placeholder secrets |
| 📚 **Docs** | Setup guides, troubleshooting notes, and references |
| 🏗️ **Patterns** | Architecture and engineering design references |
| 🤖 **Prompts** | AI prompts and agent instruction templates |
| 💻 **Commands** | Reusable CLI recipes and terminal workflows |
| 📋 **Templates** | Issue, PR, and resource documentation scaffolds |

**Design guarantees:**
- ✅ Every resource has a clearly documented purpose
- ✅ Security-sensitive content is redacted or templated
- ✅ Reuse is prioritized over reinvention
- ✅ Verification claims are backed by actual testing

## 🚀 Quick Start

### Prerequisites
- Git `>= 2.30`
- A text editor or IDE of your choice

### Clone and explore

```bash
git clone https://github.com/shaonkabir8/dev-vault.git
cd dev-vault
```

### Find a resource

```bash
# Search by keyword
grep -ri "json parse" snippets/

# List all snippets
ls snippets/
```

### Use a resource

```bash
# Copy a script into your project
cp scripts/git-cleanup.sh /path/to/your/project/scripts/

# Or reference a snippet directly
cat snippets/safe-json-parse.js
```

> **⚠️ Important:** Always review a resource's requirements, limitations, and security notes before using it. See the complete [Working Standards](./docs/README.md) in the documentation.

## 🤝 Contributing

Contributions are welcome and appreciated! Whether you are reporting a bug, suggesting a feature, improving documentation, or adding a reusable resource, please read **[CONTRIBUTING.md](./CONTRIBUTING.md)** for detailed guidelines.

### Quick Contribution Steps

1. **Fork** the repository
2. **Create** a branch (`feat/`, `fix/`, `docs/`, etc.)
3. **Implement** your change following the [Working Standards](./docs/README.md)
4. **Test** your change thoroughly
5. **Commit** using [Conventional Commits](https://www.conventionalcommits.org/)
6. **Open** a Pull Request
